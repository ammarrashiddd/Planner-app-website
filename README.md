# Planner App Website
Aplikasi manajemen aktivitas harian (To-Do List) yang memungkinkan pengguna untuk mendaftar, login, dan mengelola rencana tugas mereka secara aman di cloud.

## Demo & Deployment
* **Frontend**: Vite + React
* **Backend**: Node.js + Express (Serverless on Vercel)
* **Database**: Neon Database (PostgreSQL)
* **Live Demo**: `https://planner-app-website.vercel.app`

## Fitur Utama
* **Authentication**: Registrasi dan Login menggunakan enkripsi password dengan `bcryptjs` dan token `JWT`.
* **Activity Management**: Pengguna dapat menambah, melihat, dan menghapus aktivitas mereka sendiri.
* **Secure Connection**: Terhubung dengan Neon Database menggunakan *Connection Pooling* untuk performa maksimal di Vercel.
* **Responsive UI**: Tampilan yang bersih dan fungsional.

## Teknologi Yang Digunakan
